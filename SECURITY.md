# Security policy

## Reporting vulnerabilities

Please report exploitable vulnerabilities privately to the maintainers using GitHub's **Report a vulnerability** / private vulnerability reporting feature where enabled. If private reporting is unavailable, contact the maintainer privately rather than opening a public issue containing exploit details.

Repository: https://github.com/joeking6989/NVIQ-open

Do not disclose credentials, private customer evidence, live access tokens, or exploitable details in public issues or pull requests.

## Scope

Security reports concerning the open-source package, its dependencies, data parsing, execution boundaries, or sensitive evidence handling are welcome. The separately operated commercial service may have distinct security procedures.

## Secrets

Use environment variables or a secure secret manager for credentials. Never commit local `.env` files, captured production audio, access tokens, or proprietary customer traces.

No service-level response time or security warranty is implied by this document.
